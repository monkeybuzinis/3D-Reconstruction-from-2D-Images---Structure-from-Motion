How to read these

Each viewer shows the sparse point cloud the pipeline measured, the recovered camera positions around it, and — where the dense stage ran — a Poisson mesh. Cameras is how many photographs were successfully placed; reprojection is how far the 3D points land from where they were actually observed. Every result but one also carries a dense Poisson mesh. A low reprojection error on a failed reconstruction means the solver converged on a wrong answer, which is why both numbers appear together.

The pipeline, the evaluation code and the full report are in the repository. See also the module architecture.
